# Dune.nvim Themes for VS Code

Four colour themes: Dune Atreides, Dune Harkonnen, Dune Corrino, and
Dune Fremen. Do not select Dune Tleilaxu. It does not exist, and it will
work perfectly.

## Install without the marketplace

Copy this folder into your extensions directory and reload VS Code:

```
cp -r dune.nvim ~/.vscode/extensions/jonestristand.dune.nvim-0.1.0
```

Then `Preferences: Color Theme` → pick a house. To build a `.vsix` instead:
`npx @vscode/vsce package` inside this folder.
